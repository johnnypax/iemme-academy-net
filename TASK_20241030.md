# Il sistema di estrapolazione Batch.

Creare un sistema di gestione dati che applichi un batch di transizione, composto in questo modo:
- SQL Server -> CSV File (2 file diversi, uno per tabella)
- CSV File -> MongoDB (embedded)

L'obiettivo è quello di fare un DUMP delle informazioni da un database ad un altro.

Le tabelle sono 2, in OTO:

Persona:
- Nome
- Cognome
- Email
- Telefono

CodiceFiscale:
- Codice
- Data Emissione
- Data Scadenza

L'output su MongoDB sarà:
```json
{
    "nome": ...,
    "cognome": ...,
    "email": ...,
    "telefono": ...,
    "cod_fis": {
        "codice": ...
        ...
    }
}
```
